# 学途圈（xuetuquan）

> 面向大学生的学习成长社区小程序，基于 AI 大模型的智能学习助手。

## 🏆 项目荣誉

- 🥈 **2026年湖北中国大学生计算机设计大赛 省级二等奖**（学途圈项目）
- 🎓 本科毕业设计项目

## 项目概述

学途圈采用 **前后端分离** 架构，后端基于 **FastAPI**，前端小程序使用 **Vue 3 + Uni-app** 跨平台开发，管理端使用 **Vue 3 + Vite + Element Plus**。项目整合了 **LangChain + ChromaDB + DeepSeek**，实现基于大语言模型的 AI 问答与语义检索能力。

## 技术栈

### 后端

| 技术             | 说明                                   |
| :--------------- | :------------------------------------- |
| **FastAPI**      | 异步高性能 Web 框架，自动生成 API 文档 |
| **PostgreSQL**   | 开源关系型数据库，高扩展性、高可靠性   |
| **SQLAlchemy**   | Python ORM 框架，统一数据库操作        |
| **ChromaDB**     | 向量数据库，基于 ANN 算法实现语义检索  |
| **LangChain**    | 大语言模型应用框架，协调检索与生成     |
| **DeepSeek API** | 提供大模型推理能力                     |
| **Alembic**      | 数据库迁移工具                         |

### 前端

| 技术             | 说明                                                      |
| :--------------- | :-------------------------------------------------------- |
| **Vue 3**        | 渐进式 JavaScript 框架                                    |
| **Uni-app**      | 跨平台开发框架，一套代码多端运行（微信小程序 / H5 / App） |
| **Vite**         | 下一代前端构建工具                                        |
| **Element Plus** | 管理端 UI 组件库                                          |

## 功能模块

- 📱 **用户系统**：注册、登录、个人资料、头像
- 📝 **学习社区**：发帖、点赞、评论、分享、收藏
- 📅 **学习计划**：创建每日/每周学习计划，打卡追踪
- 🤖 **AI 问答助手**：基于 DeepSeek + LangChain 的智能问答，支持知识库检索
- 🖼️ **资源管理**：课程、资料、学习素材
- 🛠️ **管理后台**：内容审核、用户管理、数据统计

## 快速开始

### 环境要求

- Python 3.10+
- PostgreSQL 13+
- DeepSeek API Key

### 后端启动

```
# 1. 克隆项目
git clone https://github.com/wkyzcrhs/xuetuquan.git
cd server_deploy/backend

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，填入数据库连接、DeepSeek API Key 等

# 3. 安装依赖
pip install -r requirements.txt

# 4. 数据库迁移
alembic upgrade head

# 5. 启动服务
python main.py
```

服务启动后访问 `http://localhost:8000/docs` 查看自动生成的 API 文档。

## 解决的关键问题

1. **完整的项目整合**：FastAPI 后端 + SQLAlchemy ORM + LangChain/ChromaDB + DeepSeek 大模型，打通从传统 CRUD 到 AI 检索增强生成的完整链路。
2. **前后端合理分工**：小程序端使用 Vue 3 + Uni-app 实现跨平台，管理端使用 Vue 3 + Vite + Element Plus 专注后台运营，两端共享接口规范。
